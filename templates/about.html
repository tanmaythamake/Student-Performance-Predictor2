About EduPredict AI

AI Powered Student Performance Prediction System

Project Overview

EduPredict AI is a Machine Learning based Student Performance Prediction System developed to help teachers and students identify academic performance at an early stage. The system predicts future academic performance using Attendance, Study Hours, Internal Marks, Assignment Marks and Previous Semester Marks.


Project Objective

The main objective of this project is to predict student academic performance and identify students who require additional academic support before final examinations.


Key Features

  • 📊 Student Performance Prediction
  • 🤖 Machine Learning Based System
  • 📈 Performance Dashboard
  • ⚠ Risk Level Detection
  • 🏆 Grade Prediction
  • 📜 Prediction History
  • 📉 Performance Analytics
