Project Overview

Understanding the purpose of EduPredict AI

EduPredict AI is a Machine Learning based Student Performance Prediction System developed to analyze academic and learning-related information.

The system uses important student parameters such as attendance, daily study hours, internal marks, assignment performance and previous semester performance.

Based on these inputs, the trained Machine Learning model predicts the student's expected performance score and generates an expected grade and risk level.

Smart Academic Analysis

Convert student academic data into meaningful performance insights.
